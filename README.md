# n8n Automation Projects

This repository contains my n8n workflow automation assignments and projects.

## Projects

### 1. Weather Automation
- Retrieves weather information
- Uses conditional logic
- Sends email notifications

### 2. RSS News Automation
- Reads news from an RSS feed
- Filters the top headlines
- Sends automated notifications

### 3. Telegram News Automation
- Retrieves news from RSS
- Formats the latest headlines
- Sends notifications through Telegram

### 4. Webhook to Google Sheets
- Receives POST JSON data through a Webhook
- Validates submitted information
- Stores valid submissions in Google Sheets
- Adds a timestamp
- Returns success/error responses
